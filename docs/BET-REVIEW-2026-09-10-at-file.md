# 立项复盘：@file 提及插件否决案（2026-09-10）

> 一次被数据「支持」、被验证「否决」的立项。记录下来，因为这次的教训会反复用到：
> **观测站的数据回答「过去需要什么」，回答不了「平台下一步会做什么」。**

## 一、过程还原

**起点问题**：想再做一个 dsh 插件，目标是爆下载量。数据能指路吗？

**第一步：看头部赢家**（enrich.json × downloads）。发现下载量极度头部化——
dsh-market（71,224/周）、better-sidebar（59,166/周）、univer-office（30,983/周）、
dsh-context（22,556/周）、cost-meter（14,273/周）。共性：全是「入口级刚需」，
不是功能插件。反例：主题/美化类 398 个插件平均每插件 6/周。

**第二步：找「需求已验证、供给正在死」的窗口**（enrich × compat-observed）。
全生态周下载 >100 且在当前 shell 实测崩溃的只有 3 个，最扎眼的是：

- `dsh-at-file`：**1,423/周、★502、从未能用过**（15 个 shell 版本全部加载即崩，
  顶层裸 require 了从未进过任何 shell 模块表的 `@deepseek-ai/dsh-client-runtime/client`）

「每周 1,400 人安装一个必崩的插件」看起来是尖叫的需求信号。

**第三步：竞争格局**。再挖一层，发现两个**能用**的替代品已存在：

| 插件 | 状态 | 周下载 | ★ |
|---|---|---|---|
| dsh-at-file | 从未能用 | 1,423 | 502 |
| dsh-file-mention（8-19 发布） | 矩阵全绿 | 250 | 1 |
| dsh-at-mention（8-20 发布） | 矩阵全绿 | 78 | 1 |

即：能用的供给接不住流量，短板在分发和质量信号，不在功能。

**第四步（否决）：用户直觉挑战**——「官方是不是原生做了？我 dsh 里好像就能 @ 文件」。
验证结果：

1. **官方 8-27 已原生实现** web composer 的 `@` 提及（工作区文件搜索 5 万条索引 /
   会话引用 / 目录下钻 / 面包屑），feature note 状态 implemented、9-04 归档
   （`deepseek-ai/deepseek-harness` 的 `.agents/notes/archived/feature/`）。
2. better-sidebar 也带「悬浮 @文件 一键引用进输入框」。
3. 用户本机（0.1.2-rc.1）的 @ 能力正是原生功能在工作。

**结论：否决。** @file 需求已被平台原生吸收，插件进场是和平台竞争，必输。

## 二、教训（按重要度）

1. **npm 下载量是滞后指标，不是需求信号本身。**
   dsh-at-file 的 1,423/周是「原生功能上线（8-27）之前积累的流量惯性」：
   名字占位 + ★502 + 旧推荐持续导流。存量入口价值（名字/星级/先发）可以大于
   功能可用性——但也会被平台原生功能**一夜清零**。

2. **「需求被验证」必须追问：被谁验证、验证的时点、现在谁在满足。**
   @file 的需求验证发生在官方原生功能上线之前。时点错了，证据就失效了。

3. **选品必须过「平台吸收风险」筛查。** 官方 repo 的 `.agents/notes/` 特性笔记
   是公开的路线图，选品前必读。风险分层（从官方活跃开发区远近看）：

   | 插件类型 | 吸收风险 | 备注 |
   |---|---|---|
   | composer/输入框增强 | 极高 | @file 刚被吃掉 |
   | 侧栏/面板底座 | 高 | better-sidebar 在赌这个 |
   | 会话/工作区管理核心 | 中高 | 官方在猛改会话子系统 |
   | 主题/皮肤 | 中 | 官方留给生态的空间 |
   | 外部服务集成 | 低 | vision/搜索/第三方 API |
   | 领域应用 | 极低 | Office、仪表盘、画图 |

4. **「供给弱」要区分两种**：从没有人能用的（真空缺，如 dsh-at-file 名存实亡）
   vs 有人能用但没分发的（如 file-mention/at-mention）。后者说明这个 niche 的
   瓶颈是渠道而非产品——第三个进场者大概率同样接不住流量。

5. **立项的正确顺序**：需求证据 → 竞争格局 → **平台动向** → 构建成本。
   本次前两步都支持做，第三步一票否决。平台动向从此是我们选品的固定闸口。

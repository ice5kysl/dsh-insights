## Anomalies and Responses
### owner-cluster (mid)
- **Possible cause (hypothesis)**：Account uckkk uses scripts for bulk registration/template copying, generating 1286 low-quality plugins to occupy long-tail and search exposure.
- **Impact**：Ecosystem scale, weekly growth, and author rankings heavily polluted; real quality and activity diluted.
- **Recommendation**：DSH official implement dual thresholds on owner plugin count/avg score, remove or isolate uckkk and derivatives; report de-watered core metrics separately.
### owner-cluster (mid)
- **Possible cause (hypothesis)**：Account CAI-MH is a small-scale batch copy or template filling, 9 plugins avg 57 and 1 without README.
- **Impact**：Limited scope, but indicates more small batch accounts may exist below thresholds.
- **Recommendation**：Add CAI-MH to watchlist; enforce README completion or reduce discoverability.
### dominant-owner (low)
- **Possible cause (hypothesis)**：Same account as uckkk, long-term batch generation not cleaned, creating extreme 8% dominance.
- **Impact**：Inflated statistics, active rate and growth distorted, misleading authors about ecosystem prosperity.
- **Recommendation**：DSH official establish author reputation score and display on plugin pages; filter batch account content in search.
### npm-stale (low)
- **Possible cause (hypothesis)**：Publishing not automated, repo updated but npm not synced; some npm packages may be squatted or misconfigured.
- **Impact**：npm installers cannot get latest fixes; critical plugins like dsh-market, dsh-web lag behind, may hit already-fixed bugs.
- **Recommendation**：Download page explicitly show repo vs npm version diff; enable CI auto-publish for core plugins; authors verify npm token.
### breaking-release (high)
- **Possible cause (hypothesis)**：Official adjusted APIs/interfaces in v0.2.1-rc.1 and alpha.3, introducing breaking changes.
- **Impact**：5 releases this week, 2 breaking, plugin authors must adapt quickly; failure leads to runtime errors.
- **Recommendation**：Official release breaking change notice and migration scripts; plugin authors run compatibility tests and watch high-frequency defects like missing exports["./client"].

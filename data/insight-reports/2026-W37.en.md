## Anomalies & Responses
### growth-anomaly (severity: mid)
- **Possible cause (hypothesis)**: discovery/intake pipeline delay, upstream scraping frequency drop, or natural falloff after mid-August submission surge.
- **Impact**: weekly growth numbers distorted, may mask real supply rhythm; continued decline will affect ecosystem heat and user expectations.
- **Suggestion**: audit collection logs and failure queues for 09-07 to 09-13, publish official 'growth caliber' note; temporarily use 7-day average instead of single-week delta.

### dominant-owner (severity: low)
- **Possible cause (hypothesis)**: uckkk is template batch account, possibly automated testing or SEO squatting.
- **Impact**: total scale inflated 11%, author board and category distribution distorted, signal-to-noise for real plugins drops.
- **Suggestion**: add dedup toggle in author board; auto-flag accounts with >100 plugins as batch, exclude or separate in metrics.

### npm-stale (severity: low)
- **Possible cause (hypothesis)**: authors push repo without npm publish; CI publish failure or unconfigured; or squatting causing npm latest lagging.
- **Impact**: users installing from npm get outdated builds, missing fixes/features; inconsistent install experience.
- **Suggestion**: show warning on install page for repo/npm version drift (see npmStaleTop, e.g., GanyuanRan/Aegis repo 2.9.6 vs npm 0.1.0); provide one-click sync publish CI template.

### breaking-release (severity: high)
- **Possible cause (hypothesis)**: official pre-releases for 0.1.5 stable, introducing concentrated API/interface changes.
- **Impact**: plugin authors not adapting will face runtime crashes or failures, especially head plugins depending on core APIs.
- **Suggestion**: official publish breaking change list and migration guide; plugin authors should run integration tests on rc.2, watch dsh-v0.1.5-rc.1/alpha.2/alpha.1 impact.

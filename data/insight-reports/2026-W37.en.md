## 7. Anomalies & Responses
### growth-anomaly (severity: mid)
- **Possible cause (hypothesis)**: Discovery/intake pipeline adjustment, or natural decline after August batch submission wave, or crawler rate limiting.
- **Impact**: Short-term growth metrics distorted, misleading ecosystem health and trend judgments.
- **Response**: Audit intake logs vs source data, separate organic from batch imports; adopt 4-week rolling average.

### dominant-owner (severity: low)
- **Possible cause (hypothesis)**: uckkk is a template batch-generation account, not manual creation.
- **Impact**: Inflated scale numbers, author leaderboard and quality percentiles pulled down, users cannot distinguish real authors.
- **Response**: Mark or exclude this account in official statistics, set per-owner plugin cap, tag batch-generated plugins separately.

### npm-stale (severity: low)
- **Possible cause (hypothesis)**: Authors update repos but don't publish to npm promptly, or publish process not automated.
- **Impact**: npm users get old versions, missing features/fixes, may be incompatible with latest dsh.
- **Response**: Show “repo ahead of npm” risk in market, notify maintainers, provide publishing CI template.

### breaking-release (severity: high)
- **Possible cause (hypothesis)**: Official API adjustments to converge design, concentrated breaking changes before rc.
- **Impact**: Many plugins may break due to interface incompatibility; users face plugin failure after upgrade.
- **Response**: Publish migration guide and compatibility test suite, offer transition versions for high-risk breaking changes; plugin authors must immediately regression-test.

  - Prefer inImsai/inAwesome or S/A-grade plugins; watch missing files and no-client-export warnings.

  - Exclude or tag uckkk-style batch accounts from official stats; publish de-watered scale and quality metrics.
  - Launch npm drift auto-alerts, highlight “repo ahead of npm” tag on market cards.
  - Provide migration guide and automated plugin compatibility test platform for breaking releases.
  - Curate high-quality low-usage gems from quadrant.gems into recommendation slots to improve discoverability.

## Anomalies and Response

### dominant-owner (severity: low)
- **Possible cause (hypothesis)**: uckkk is automated template batch account, generating low-differentiation plugins to occupy space or visibility.
- **Impact**: 12% of ecosystem at avg 61, drags quality, adds noise, pollutes author rankings.
- **Suggested action**: enforce per-account plugin limits or downrank low-score batches; users rely on curated lists.

### concentration (severity: low)
- **Possible cause (hypothesis)**: marketplace entry and high-frequency tools dominate distribution; long tail lacks exposure mechanisms.
- **Impact**: Top 10 downloads 70%, new authors struggle, innovation may be suppressed.
- **Suggested action**: official "rising stars/editor picks"; authors use scenario packs.

### npm-stale (severity: low)
- **Possible cause (hypothesis)**: authors forget to publish npm after repo updates, or npm names squatted.
- **Impact**: users install outdated versions, missing features or security fixes; version fragmentation.
- **Suggested action**: authors set up CI auto-publish; official prompts stale warnings and sync guide.

### breaking-release (severity: high)
- **Possible cause (hypothesis)**: core API rapid iteration; 0.1.5 series introduces breaking changes, multiple alpha/rc for feedback.
- **Impact**: existing plugins may break; users face incompatibility; adaptation burden on authors.
- **Suggested action**: official provide migration guide and compat layer; authors immediately test against rc.2 stability.

## Next Steps and Recommendations

- **Plugin authors**: prioritize adapting to dsh-v0.1.5-rc.2 with regression tests; verify npm sync before publish; package into scenarios; avoid templating, differentiate.
- **Ecosystem users**: check npm vs repo version before install; be cautious with 0-star high-download plugins like DSH-better-sidebar; pause auto-update during breaking releases.
- **DSH official**: govern uckkk batch accounts with clear penalties; clarify dsh-market download attribution; provide breaking migration guide and compatibility labels; improve recommendation to break Top 10 concentration.
